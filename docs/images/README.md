# Documentation images

These images are committed locally so the guides do not rely on external image hosts.

| File                       | Source and purpose                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `browser-download.png`     | Computer-use capture of the browser repository's Code menu on 2026-09-06; shows Download ZIP.                    |
| `browser-build-folder.png` | Computer-use capture of `build-chrome` on GitHub on 2026-09-06; shows the directory users should select locally. |
| `vscode-marketplace.png`   | Computer-use capture of the Rewst Buddy Marketplace installation section on 2026-09-06.                          |
| `how-it-connects.svg`      | Authored connection diagram, not a screenshot. Editable SVG with accessible title and description.               |

Screenshots are cropped directly during browser capture to show the relevant public UI. No session cookies, organization data, or credentials are included. Chrome's internal extension manager and native VS Code were unavailable to the capture session; the documentation does not represent diagrams as screenshots of those interfaces.

To refresh a capture, visit the named public page, display the documented state, and capture the relevant section. Keep filenames stable, verify the image at README width, and update this record if the UI or source changes.
